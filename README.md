# Programa Bilíngue Prime Enfant — versão original V1

Esta pasta contém **exatamente a primeira versão** da apresentação HTML gerada originalmente.

## Estrutura

- `index.html` — cópia da primeira versão, renomeada para funcionar diretamente no GitHub Pages.
- `proposta_programa_bilingue_prime_enfant.html` — o mesmo arquivo preservando o nome original.

A versão V1 é **autocontida**: CSS e JavaScript estão embutidos no próprio HTML. Por isso não há `styles.css` ou `script.js` separados nesta versão.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve.

## Editar

Abra `index.html` em um editor como VS Code. O CSS está dentro da tag `<style>` no `<head>` e o JavaScript está dentro da tag `<script>` no próprio documento.
